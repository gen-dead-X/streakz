# Ink & Ember UI Revamp — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Streakz's entire visual layer — tokens, UI kit, shell, every screen — as the "Ink & Ember" design system, removing Ant Design, while preserving all functionality.

**Architecture:** Foundation-first: rewrite CSS tokens + fonts + motion constants, build a custom accessible UI kit (Tailwind 4 + Framer Motion + Lucide), re-skin the shell, then each screen, then remove antd. Data layer (models, services, stores, API routes, streak calculators) is untouched.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind CSS 4 (CSS-first `@theme`), Framer Motion 12, lucide-react, react-hook-form + zod, zustand, canvas-confetti, notistack (kept, custom-rendered), Bun.

**Spec:** `docs/superpowers/specs/2026-07-02-ui-revamp-design.md`

## Global Constraints

- **Bun only**: `bun add` / `bun remove` / `bun run` — never npm/yarn/pnpm.
- **Mandatory doc reads before edits** (AGENTS.md): `docs/guides/nextjs.md`, `docs/guides/react.md`, `docs/guides/tailwind.md`, `docs/guides/bun.md`, `docs/STRUCTURE.md`, `docs/theme.md` (after Task 1, the rewritten version).
- **No hardcoded colors in components** — semantic CSS variables only. Raw hsl/hex values may appear ONLY in `app/globals.css` and `docs/theme.md`.
- **No `any`** — use `unknown` + narrowing. Component props always typed; non-trivial props in `ComponentName.types.ts`.
- **File placement per `docs/STRUCTURE.md`**: every component in its own PascalCase folder with `index.ts` re-export; hooks in `hooks/<domain>/useX.ts`; constants in `constants/<domain>/<name>.constants.ts`.
- **Tailwind v4**: no `tailwind.config.js`; tokens live in `@theme {}` in `app/globals.css`. No default palette classes (`text-green-500` etc.) — they don't exist.
- **React 19**: function components only; `ref` as a normal prop (no `forwardRef`); `'use client'` only where interactivity requires it, as deep as possible.
- **Accessibility**: every interactive component keyboard-operable, `focus-visible` ring using `--ring`, ARIA roles/labels, ≥44px touch targets, `prefers-reduced-motion` respected (use framer-motion's `useReducedMotion`).
- **Fonts**: `--font-display` (Bricolage Grotesque) for greetings/hero numbers/page titles; `--font-sans` (Geist) elsewhere; `tabular-nums` for counters.
- **Verification per task**: `bun run build` must pass. Existing tests must keep passing: `bun test` (covers `lib/streak`, `lib/validation`).
- **Commit after every task** with a conventional-commit message.
- **antd may not be imported in any NEW code.** Existing antd imports are removed screen-by-screen; the package is uninstalled in the final task.
